# 数据定位过程

本文记录《赵云与阿斗》各项数值的真实字段位置，供复现与学习。

## 游戏加载链路

```
h.4399.com/play/262277.htm                         顶层，无游戏
└─ iframe#gamelink → sda.4399.com/.../index.html   h5mini 壳
   └─ iframe → sda.4399.com/.../gameIndex.html     Laya 游戏本体
```

`h.4399.com/zzy/262277.htm` 是**详情页**，需点「开始游戏」才跳到 `/play/`。

## 存档

- 存储方式：`Laya.LocalStorage.setItem('playerData', JSON.stringify(this._data))`
- key：`playerData`（不是混淆代码里的 `customPropsCheckbox`，那只是代码字面量）

关键字段：

| 字段 | 含义 |
|---|---|
| `_gold` | 铜币 |
| `_stamina` | 馒头（体力）|
| `_lastRecoverStaminaTime` | 体力上次恢复时间戳 |
| `_props` | 道具数组，元素为 `[type, level, acquireTime]` |
| `_weaponFree` | 免费刷新标记 |

### 道具 type 表

| type | 名称 | 上限 |
|---|---|---|
| 0 | 铲子 | 999 |
| 2 | 毛笔 | 50 |
| 5 | 包子 | 50 |
| 7 | 砚台 | 30 |
| 8 | 陷阱 | 35 |
| 9 | 地雷 | 50 |
| 12 | 农民 | 90 |
| 9 后面 | 淤泥 | 40 |

注意：`_props` 只装建筑类道具，**武将/字走独立系统**（`_weaponFragments` / `_newWeaponIds`）。

## 战斗内对象

挂载路径（战斗中才存在）：

```js
Laya.stage._children[i]._children[j].Gw
```

`Gw` 上：

| 字段 | 含义 | 说明 |
|---|---|---|
| `Q2._gold` | 战斗金币真值 | getter `gold` |
| `Q2.Gs` | 征兵消耗 | 每帧重算，默认 10 |
| `Q2.Js` | 波次计数 | getter `Mi` |
| `_player._data._stamina` | 馒头真值 | getter `stamina` |
| `_stamina.m2` | 体力上限 | 默认 30 |
| `_stamina.S2` | 单次征兵扣体力 | 默认 5 |

### 构造函数初始值

```js
this["Os"] = 20;    // 初始金币
this["Gs"] = 10;    // 征兵消耗
this["Ys"] = 10;
this["Ws"] = 3;
this["js"] = 3;

gameOver() {
  this['Gs'] = 10;   // 跨局重置
}
```

## 「馒头不足」的真实语义

实测现象：

- 馒头真值 9999
- `Q2._gold` 100000
- 点征兵 → 仍弹「馒头不足」

逐字段 diff 定位：

```
点击前: _gold 100002
点击后: _gold 1
```

**结论：征兵扣的是金币 `_gold`，不是馒头。**
「馒头不足」是复用的通用提示文案，与实际判定无关。

## 广告接口

```js
window.h5api.playAd(callback)           // 激励视频
window.h5api.playYlhAd(pid, callback)   // 优量汇
window.h5api.playInterstitialAd()       // 插屏
window.h5api.canPlayAd(callback)        // 是否可播
```

回调结构需为 `{ ok: true, isEnded: true, code: 0, success: true }`。
