# 踩坑记录

按时间顺序记录失败与修正，避免重复踩。

## 坑 1：把 999 个铲子塞进存档 → 游戏卡死

**做法**：`_props` 写 999 个 `[0,1,ts]`

**现象**：

```
[ERROR] TypeError: Cannot set properties of undefined (setting '0')
[ERROR] TypeError: Cannot read properties of null (reading 'graphics')  ×4
```

界面卡在「匹配完成」，弹窗关不掉。

**原因**：道具栏 `propsBox` 只有 **8 个格子**。

```js
for (let i = 0; i < activePropsBox.numChildren; i++)   // 只跑 8 次
    i < rD.length ? render(i, rD[i]) : hide(i)
```

`rD` 有 999 项，格子只有 8 个 → 第 9 项找不到节点 → 崩。

**修正**：`_props` 最多 8 项，用掉后自动补。

## 坑 2：改存档不等于改显示

**做法**：直接改 `playerData._stamina = 9999`

**现象**：存档是 9999，UI 显示 `30/30`

**原因**：游戏启动时执行 `Math.min(stamina, m2)`，`m2` 默认 30，把值钳回去了。

**修正**：同时改 `Gw._stamina.m2`，并 Hook UI 的 `text` setter。

---

## 坑 3：改 `Gs` 无效，每帧被重算

**做法**：`Q2.Gs = 0` 想免除征兵消耗

**现象**：当次有效（`costPerClick = 0`），下一帧又变回 10 / 64 / 100001

**原因**：`Gs` 在渲染循环里被反复赋值。

**修正**：接管 setter，拒绝变小。

```js
Object.defineProperty(Q2, 'Gs', {
  get: function () { return 2; },
  set: function () {}
});
```

---

## 坑 4：Hook 显示层 → 逻辑仍不通过

**做法**：Hook `goldNum` / `staminaTxt` 的 `text` setter，永远显示 9999

**现象**：数字好看，但点征兵照样弹「馒头不足」

**原因**：判定走的是真实字段，UI 只是渲染结果。

**教训**：**改显示 ≠ 改逻辑**。必须找到数据源对象。

---

## 坑 5：找错馒头字段

**过程**：

1. 以为馒头是 `Q2.Js` → 拉高 9999，仍报错
2. 以为馒头是 `Gw._stamina.m2` → 拉高，仍报错
3. 最后逐字段 diff 发现扣的是 `Q2._gold`

**教训**：不要猜字段名，用「点击前后 diff」实测。

## 坑 6：字符串拼接注入 → Via 语法崩溃

**做法**：

```js
var PATCH_SRC = '(' + function () { ... } + ')();';
doc.head.appendChild(script(PATCH_SRC));
```

**现象**（Via 日志）：

```
[ERROR] Uncaught SyntaxError: Invalid or unexpected token   × 18
```

脚本从未执行。

**原因**：`Function.prototype.toString()` 在部分内核会带上注释、
特殊字符（中文、模板字符串、正则字面量），拼出来不是合法 JS。

**修正**：

- 核心代码收紧成纯函数 `CORE`，去掉中文注释与特殊字符
- 用 `new Function('(' + CORE.toString() + ')()')` **先验证可解析**
- 注入时 `try/catch` 包裹

## 坑 7：@match 漏了真正的游戏页

**做法**：`@match https://h.4399.com/zzy/262277.htm*`

**现象**：脚本在详情页跑，那页根本没有游戏。

**修正**：加上 `/play/262277.htm` 与游戏资源域。

## 坑 8：直接打开 gameIndex.html 无法运行

**做法**：为了绕开 iframe，直接访问游戏本体地址

**现象**：

```
hasCanvas: 0
hasLaya: undefined
title: "page err"
```

**原因**：缺少 4399 播放器上下文（referer / h5api），
`libs/laya.core.js` 等资源加载失败。

**结论**：必须走播放页，靠顶层下钻注入。

---

## 坑 9：Via 不读 @all-frames

**现象**：顶层 `booted: true`，iframe 内 `booted: false`

**修正**：不依赖 @all-frames，由顶层脚本自己递归下钻：

```js
function diveDoc(doc, depth) {
  if (depth > 4) return;
  var frames = doc.querySelectorAll('iframe');
  for (var i = 0; i < frames.length; i++) {
    var sub = frames[i].contentDocument;   // 跨域会抛异常，用 try 包
    if (!sub) continue;
    injectDoc(sub);
    diveDoc(sub, depth + 1);
  }
}
```

前提是 `contentDocument` 可读（4399 三层都设了 `document.domain = "4399.com"`）。
