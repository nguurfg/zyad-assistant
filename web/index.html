⚠ 先看这条
游戏是三层嵌套的，部分浏览器不会往 iframe 注入脚本。 Via 用户请先开「允许网页脚本」开关，否则脚本一行都不执行。

⬇ 下载脚本 从 Raw 地址安装（油猴自动识别）

Android 上最稳的方案，支持完整油猴能力。

  1. 打开 Via 菜单 → 设置 → 通用（或「脚本」）
    勾选 允许网页脚本
    这一步不做，脚本完全不会执行。
  2. 下载脚本文件，Via 会提示「安装脚本」→ 确认
  3. 打开游戏页进战斗
  4. 验证：地址栏输入 javascript: 开头的调试代码，或看消耗数字

Via 对跨域 iframe 的 contentDocument 访问有限制。 本脚本 v15.0 已改为顶层递归下钻注入，多数情况可用。 仍不行就换 Kiwi。

iOS Safari 不支持用户脚本注入。

需要装 Stay 或 Browsers 这类支持 Userscript 的 App， 并在其设置里导入本仓库的 raw 地址。

⑥ 排障

数字没变？

  1. 确认从 /play/ 页进入，不是 /zzy/
  2. 刷新一次页面（脚本在 DOM 就绪后注入）
  3. 控制台看有无 [ZYAD] core installed 日志
  4. 执行 __ZYAD_TOP__.status()，看 gameIndex.html 那层是否 booted: true
  5. Via 用户确认「允许网页脚本」已开
