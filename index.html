一键安装

⬇ 一键安装脚本 点这里 → 浏览器弹出「安装脚本」→ 点确认
1
点上面的蓝色按钮
2
浏览器弹出安装确认框 → 点 安装
如果只看到一堆代码、没弹框，说明当前浏览器不支持用户脚本，看下面「分平台说明」
3
打开游戏页 → 进战斗 → 看到左上角消耗显示 2 就成功了
🔗 备用地址（Raw）· 油猴也能识别 🎮 直接打开游戏
⚠ Via 用户注意
必须先开 Via 菜单 → 设置 → 通用/脚本 → 允许网页脚本， 否则脚本一行都不执行。

装好后怎么确认生效

左上角征兵消耗固定 2

Android 上最稳的方案，完整支持油猴能力。

第一步必须先做
Via 菜单 → 设置 → 通用（或「脚本」）→ 勾选 允许网页脚本
  1. 开启上面的开关
  2. 点「⬇ 一键安装脚本」，Via 会提示安装 → 确认
  3. 打开游戏页进战斗

Via 对跨域 iframe 的 contentDocument 访问有限制。 本脚本已改为顶层递归下钻注入，多数情况可用；仍不行请换 Kiwi。

iOS Safari 不支持用户脚本注入

需要装 Stay 或 Browsers 这类支持 Userscript 的 App， 在其设置里导入下面的 Raw 地址： 

https://raw.githubusercontent.com/nguurfg/zyad-assistant/main/userscript/zyad-assistant.user.js

任意支持用户脚本的浏览器，手动添加：

https://nguurfg.github.io/zyad-assistant/userscript/zyad-assistant.user.js

数字没变？按顺序排查

1
确认从 /play/262277.htm 进入，不是 /zzy/ 详情页
2
刷新一次页面（脚本在 DOM 就绪后注入）
3
控制台看有没有 [ZYAD] core installed
4
执行 __ZYAD_TOP__.status()，看 gameIndex.html 那层是否 booted: true
5
Via 用户确认「允许网页脚本」已开
